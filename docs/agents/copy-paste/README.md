# ShiftTrack Agents · Copy / Paste Pack

Esta carpeta deja los mismos agentes en un formato más práctico para copiar y pegar en herramientas comunes.

## Archivos

- `cursor-prompts.md`
- `copilot-prompts.md`
- `claude-prompts.md`

## Cómo usarlos

1. Abre el archivo de la herramienta que uses.
2. Busca el agente que necesitas.
3. Copia el bloque completo.
4. Pégalo como prompt base, custom instruction o system prompt.
5. Debajo agrega la tarea concreta.
